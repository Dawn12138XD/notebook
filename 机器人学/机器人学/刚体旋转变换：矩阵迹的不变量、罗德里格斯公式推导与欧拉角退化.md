# 刚体旋转变换：矩阵迹的不变量、罗德里格斯公式推导与欧拉角退化

> 💡 **核心本质与痛点**：任意三维旋转在本质上都是一维刚体沿特定单位轴的单自由度扭转。利用相似变换的迹不变量，可绕过复杂的非线性三角方程，直接由矩阵对角线元素提取旋转角；同时，罗德里格斯公式与欧拉角/RPY 逆解必须在投影代数与数值计算上规避奇异点（万向节死锁）与求逆灵敏度漂移。
> 
>   

## 直观物理与几何图景拆解

### 1. 相似变换 $R_k(\theta) = C R_z(\theta) C^{-1}$ 的视线桥梁

直接求取绕空间任意倾斜轴 $\boldsymbol{k} = [k_x, k_y, k_z]^T$ 的旋转矩阵极其繁复。通过引入**随动正交辅助标架** $C = [\boldsymbol{n} \ \ \boldsymbol{o} \ \ \boldsymbol{a}]$，令其第三主轴 $\boldsymbol{a}$ 严格与待转轴 $\boldsymbol{k}$ 重合（即 $\boldsymbol{a} = \boldsymbol{k}$）：

  

```
    全局坐标系 {0}                      辅助标架系 {C}
       p_0 (初始点)    ──(C^-1 左乘)──>    p_C = C^-1 * p_0
            │                                   │
            │ (目标变换 R_k)                     │ (标准基旋转 R_z(θ))
            ▼                                   ▼
       p_0' (旋转终点)  <──( C 左乘 )────   p_C' = R_z(θ) * p_C
```

整个变换拆解为三步连续操作：

  

1. **投影视角转换（入系）**：全局向量 $\boldsymbol{p}_0$ 投影至标架 $C$ 的三个轴上，得到内部表象 $\boldsymbol{p}_C = C^{-1} \boldsymbol{p}_0$。
    
      
    
2. **基准轴规整旋转（变换）**：在标架内部绕标准基轴 $\boldsymbol{z}$ 旋转 $\theta$，矩阵退化为初等旋转矩阵 $R_z(\theta)$。
    
      
    
3. **坐标真实还原（出系）**：将旋转后的标架内部坐标 $\boldsymbol{p}_C'$ 重新投影回全局基座空间 $\boldsymbol{p}_0' = C \boldsymbol{p}_C'$。
    
      
    

### 2. 为什么旋转矩阵的迹等于 $1 + 2\cos\theta$？

矩阵的迹（对角线元素之和）在几何上是**线性变换在内积空间中的刚性不变量**。

因为任何三维旋转均与初等旋转 $R_z(\theta)$ 相似：

  

$$R_k(\theta) = C R_z(\theta) C^{-1}$$

初等绕 $Z$ 轴旋转矩阵的迹显而易见：

  

$$\text{tr}(R_z(\theta)) = \cos\theta + \cos\theta + 1 = 1 + 2\cos\theta$$

根据相似变换的迹不变性：

  

$$\text{tr}(R_k(\theta)) = \text{tr}(C R_z(\theta) C^{-1}) = \text{tr}(R_z(\theta) C^{-1} C) = \text{tr}(R_z(\theta)) = 1 + 2\cos\theta$$

该性质无需展开任何矩阵分量，直接证明了**空间任意旋转矩阵的主对角线之和只取决于旋转绝对角 $\theta$，与旋转轴的空间朝向完全解耦**。

  

## 关键推导断层精析（防卡壳指南）

### 断层 1：为什么进入辅助坐标系一定要左乘 $C^{-1}$？

**卡壳诱因**：常误以为“从基座系进入系 $C$ 需要乘以 $C$”。

  

**严格代数还原**：

设标架 $C$ 的三个基底向量在基础坐标系 $\{0\}$ 下分别表示为 $\boldsymbol{n}, \boldsymbol{o}, \boldsymbol{a}$。

任意向量在标架 $C$ 下的分量坐标为 $\boldsymbol{p}_C = [x_C, y_C, z_C]^T$。

由向量的几何线性组合定义，该向量在基础系下的物理真实坐标为：

  

$$\boldsymbol{p}_0 = x_C \boldsymbol{n} + y_C \boldsymbol{o} + z_C \boldsymbol{a} = [\boldsymbol{n} \ \ \boldsymbol{o} \ \ \boldsymbol{a}] \begin{bmatrix} x_C \\ y_C \\ z_C \end{bmatrix} = C \boldsymbol{p}_C$$

因此，矩阵 $C$ 的正向物理含义是“将局部标架内的坐标合成还原为全局基准坐标”。

若已知全局坐标 $\boldsymbol{p}_0$ 反求其在局部标架下的分量，两边必须同乘逆矩阵：

  

$$\boldsymbol{p}_C = C^{-1} \boldsymbol{p}_0$$

因 $C$ 属于特殊正交群 [[正交旋转矩阵]] $SO(3)$，满足 $C^{-1} = C^T$。

  

### 断层 2：标架向量 $\boldsymbol{n}, \boldsymbol{o}$ 是如何被消除并导出罗德里格斯公式的？

**卡壳诱因**：标架矩阵 $C$ 含有辅助基向量 $\boldsymbol{n}, \boldsymbol{o}$，但在最终形式中消失，仅留下了旋转轴分量 $\boldsymbol{k} = \boldsymbol{a} = [k_x, k_y, k_z]^T$。

  

**消除步进推导**：

展开外积块矩阵乘法，已知 $C = [\boldsymbol{n} \ \ \boldsymbol{o} \ \ \boldsymbol{a}]$ 且 $C^{-1} = C^T = [\boldsymbol{n} \ \ \boldsymbol{o} \ \ \boldsymbol{a}]^T$：

  

$$ R_k(\theta) = C \begin{bmatrix} \cos\theta & -\sin\theta & 0 \ \sin\theta & \cos\theta & 0 \ 0 & 0 & 1 \end{bmatrix} C^T $$

  

$$R_k(\theta) = \cos\theta (\boldsymbol{n}\boldsymbol{n}^T + \boldsymbol{o}\boldsymbol{o}^T) + \sin\theta (\boldsymbol{o}\boldsymbol{n}^T - \boldsymbol{n}\boldsymbol{o}^T) + \boldsymbol{a}\boldsymbol{a}^T$$

代入正交完备标架的两大几何约束恒等式：

  

1. **空间完备性分解**：
    
    $\boldsymbol{n}\boldsymbol{n}^T + \boldsymbol{o}\boldsymbol{o}^T + \boldsymbol{a}\boldsymbol{a}^T = I \implies \boldsymbol{n}\boldsymbol{n}^T + \boldsymbol{o}\boldsymbol{o}^T = I - \boldsymbol{a}\boldsymbol{a}^T$
    
      
    
2. **右手系叉乘反对称映射**：
    
    因为 $\boldsymbol{n} \times \boldsymbol{o} = \boldsymbol{a}$，对应外积算子展开即为外积差矩阵：
    
    $\boldsymbol{o}\boldsymbol{n}^T - \boldsymbol{n}\boldsymbol{o}^T = [\boldsymbol{a}]_\times$
    
      
    

将上述两式代回，消去所有关于标架轴 $\boldsymbol{n}, \boldsymbol{o}$ 的项，即得到**罗德里格斯旋转公式（[[Rodrigues旋转公式]]）**：

  

$$R_k(\theta) = I\cos\theta + (1 - \cos\theta)\boldsymbol{a}\boldsymbol{a}^T + \sin\theta [\boldsymbol{a}]_\times$$

定义正矢函数 $\text{vers}\theta = 1 - \cos\theta$，将单位转轴 $\boldsymbol{a} = [k_x, k_y, k_z]^T$ 展开为分量形式，即得到标准展开式：

  

$$R_k(\theta) = \begin{bmatrix} k_x^2 \text{vers}\theta + \cos\theta & k_x k_y \text{vers}\theta - k_z \sin\theta & k_x k_z \text{vers}\theta + k_y \sin\theta \\ k_x k_y \text{vers}\theta + k_z \sin\theta & k_y^2 \text{vers}\theta + \cos\theta & k_y k_z \text{vers}\theta - k_x \sin\theta \\ k_x k_z \text{vers}\theta - k_y \sin\theta & k_y k_z \text{vers}\theta + k_x \sin\theta & k_z^2 \text{vers}\theta + \cos\theta \end{bmatrix}$$

对该矩阵求主对角线元素和（迹），利用 $k_x^2 + k_y^2 + k_z^2 = 1$：

  

$$\text{tr}(R_k(\theta)) = (k_x^2 + k_y^2 + k_z^2)(1 - \cos\theta) + 3\cos\theta = 1 - \cos\theta + 3\cos\theta = 1 + 2\cos\theta$$

若为 $4 \times 4$ 齐次变换矩阵 $T$，右下角包含第 4 行第 4 列的标量 $1$，总迹值为：

  

$$\text{tr}(T) = 2 + 2\cos\theta$$

## 易混淆横向对比表

### 1. 迹（Trace）的关键数学性质与矩阵类型关联

|**矩阵类型 / 运算操作**|**迹的数学行为**|**证明或关键结论**|
|---|---|---|
|**相似矩阵**($B = P^{-1}AP$)|$\text{tr}(B) = \text{tr}(A)$|由轮换对称性：$\text{tr}(P^{-1}AP) = \text{tr}(APP^{-1}) = \text{tr}(A)$|
|**可逆矩阵**($A \in GL(n)$)|迹**无固定常数或符号约束**|可逆仅保证 $\det(A) \neq 0$；$\text{tr}(A^{-1}) \neq \frac{1}{\text{tr}(A)}$，实为 $\sum \frac{1}{\lambda_i}$|
|**正交/旋转矩阵** ($R \in SO(3)$)|$\text{tr}(R) = 1 + 2\cos\theta \in [-1, 3]$|特征值为 $1, e^{i\theta}, e^{-i\theta}$，和恒为 $1 + 2\cos\theta$|
|**对换子（李代数支柱）**|$\text{tr}([A, B]) = \text{tr}(AB - BA) \equiv 0$|证明有限维空间中不存在满足 $AB - BA = I$ 的矩阵算符|
|**转置与共轭转置**|$\text{tr}(A^T) = \text{tr}(A)$，$\text{tr}(A^H) = \overline{\text{tr}(A)}$|对角线元素不受非对角置换影响|

## 工程踩坑与数值解算优化

### 1. 为什么姿态反解严禁使用 $\arccos$ / $\arcsin$ 而必须用 $\text{atan2}$？

在通过旋转矩阵元素反解角度时，算法如果直接采用 $\theta = \arccos(y)$ 或 $\theta = \arcsin(y)$，在工程控制底层极易引发崩溃：

  

1. **数值梯度在极值区发散（噪声放大）**：
    
      
    
    $$\frac{d}{dy}\arccos(y) = -\frac{1}{\sqrt{1 - y^2}}$$
    
    当旋转角接近 $0^\circ$（即 $y = \cos\theta \approx 1$）时，导数分母趋近于 0，导数值逼近无穷大。机械臂传感器或浮点截断带来的微小扰动 $\Delta y$ 会被放大成极大的姿态角度抖动。
    
      
    
2. **多值性与象限截断**：
    
    $\arccos$ 的值域仅覆盖 $[0, \pi]$，完全无法判别正负旋转角（$\cos\theta = \cos(-\theta)$）。
    
      
    
3. **安全替代方案**：
    
    在工业机器人控制器中，统一采用双参数反正切函数 `atan2(sin_val, cos_val)`，在 $[-\pi, \pi]$ 全周天内保持全局一致的数值鲁棒性与象限唯一性。
    
      
    

### 2. 轴角求解的 Python 最小鲁棒算例

Python

```
import numpy as np

def rotation_matrix_to_axis_angle(R: np.ndarray):
    """
    通过矩阵的迹 (Trace) 与反对称部分，数值稳定地反解旋转角与旋转轴
    """
    assert R.shape == (3, 3), "输入矩阵必须为 3x3"
    
    # 1. 利用迹提取旋转角 theta
    tr = np.trace(R)
    # 数值截断保护：防止浮点误差导致 tr 超出 [-1, 3] 理论区间
    cos_theta = np.clip((tr - 1.0) / 2.0, -1.0, 1.0)
    theta = np.arccos(cos_theta)
    
    # 2. 极值判别与轴向量解算
    if np.isclose(theta, 0.0):
        # 旋转角为 0 时，轴向任意，定义为零向量
        return np.array([0.0, 0.0, 1.0]), 0.0
    
    if np.isclose(theta, np.pi):
        # 旋转角为 180 度时的临界情况：反对称项抵消为 0，需从对角线二次型提取轴
        kx = np.sqrt(max(0.0, (R[0, 0] + 1.0) / 2.0))
        ky = np.sqrt(max(0.0, (R[1, 1] + 1.0) / 2.0)) * np.sign(R[0, 1])
        kz = np.sqrt(max(0.0, (R[2, 2] + 1.0) / 2.0)) * np.sign(R[0, 2])
        axis = np.array([kx, ky, kz])
        return axis / np.linalg.norm(axis), theta

    # 3. 通用非奇异状态：提取反对称矩阵 [k]_x = (R - R^T) / (2 * sin(theta))
    # 结合 sin(theta) 符号使用 atan2 保证全象限鲁棒性
    sin_theta = np.sin(theta)
    kx = (R[2, 1] - R[1, 2]) / (2.0 * sin_theta)
    ky = (R[0, 2] - R[2, 0]) / (2.0 * sin_theta)
    kz = (R[1, 0] - R[0, 1]) / (2.0 * sin_theta)
    
    axis = np.array([kx, ky, kz])
    return axis / np.linalg.norm(axis), theta

# 验证算例：绕轴 [1, 1, 0] 旋转 60 度
axis_true = np.array([1.0, 1.0, 0.0]) / np.sqrt(2.0)
theta_true = np.radians(60.0)

# 罗德里格斯公式构造矩阵
K = np.array([
    [0.0, -axis_true[2], axis_true[1]],
    [axis_true[2], 0.0, -axis_true[0]],
    [-axis_true[1], axis_true[0], 0.0]
])
R_test = np.eye(3) * np.cos(theta_true) + (1.0 - np.cos(theta_true)) * np.outer(axis_true, axis_true) + np.sin(theta_true) * K

axis_calc, theta_calc = rotation_matrix_to_axis_angle(R_test)
print(f"解析角误差: {np.abs(theta_calc - theta_true):.2e} rad")
print(f"解析轴误差: {np.linalg.norm(axis_calc - axis_true):.2e}")
```
