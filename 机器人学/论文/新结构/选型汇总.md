# 高精度机械臂
### 电路精密焊接机械臂工程方案（精简版）

### 一、 核心架构：粗精解耦（Macro-Mini 混合驱动）

Plaintext

```
[ 基座与大臂 J1-J3 ]  ──>  [ 手腕姿态 J4-J6 ]  ──>  [ 末端微动执行器 (Z轴) ]
   中空无刷谐波模组          小型无刷谐波模组          单轴音圈微动台 + 柔性导轨
 (大刚度 / 零背隙定位)     (中空走线 / 姿态微调)      (微米级点动 / 0.5~1.5N 恒力接触)
```

### 二、 硬件选型与机构配置

|**模块**|**执行机构 / 传动方案**|**减速比 / 规格**|**核心功能与选型理由**|
|---|---|---|---|
|**基座 / 肩 / 肘 (J1~J3)**|**无刷谐波模组**（配双绝对值编码器）|**80:1 ~ 100:1**（14/17 型）|消除齿隙（回差 < 1 弧分），提供大刚度与悬停力矩，彻底避免发热漂移；全中空走线。|
|**重力平衡 (J2/J3 辅助)**|机械弹簧 / 气弹簧辅助连杆|机械无源补偿|抵消 80% 悬臂静重力矩，大幅降低大臂关节功耗与热变形。|
|**手腕 (J4~J6)**|**超轻型中空谐波模组**|**50:1 ~ 80:1**（11/14 型）|外径小（$\Phi 40 \sim 50\text{ mm}$），避让密集元件，内部走加热与送丝管路。|
|**末端接触轴 (Z 向微动)**|**音圈电机 (VCA)** + 弹簧片柔性并联导轨|**直接驱动 (1:1)**，量程 3~5 mm|**零摩擦、零背隙**。安培力闭环控制，烙铁头下压时提供 0.5~1.5 N 柔顺恒力，防止压损焊盘。|
|**感知与供料**|微距工业相机 + 自动送锡机构|环形 LED + 微型步进送丝|手眼标定精确定位焊盘；独立送锡管定点定量吐锡。|

### 三、 控制与作业时序

1. **粗定位阶段（谐波臂运动）：**
    
      
    
    根据全局视觉检测结果，J1~J6 关节插补运动，将烙铁头精确送至焊盘正上方 **1.0 ~ 2.0 mm** 悬停，末端闭环锁定。
    
      
    
2. **精对齐阶段（局部微调）：**
    
      
    
    手眼相机微距闭环，末端手腕微调俯仰/偏航角，确保烙铁刃面与引脚、焊盘完全平行。
    
      
    
3. **焊接接触阶段（音圈恒力下压）：**
    
      
    
    大臂保持刚性锁定，音圈电机以低流限（恒定微力模式）驱动烙铁头下移接触焊盘，检测到位移与接触力稳定在预设值（如 0.8 N）。
    
      
    
4. **送丝与回退：**
    
      
    
    预热 0.5~1.0 s $\rightarrow$ 步进电机定量送锡 $\rightarrow$ 润湿成形 $\rightarrow$ 音圈电机快速抬升 2 mm $\rightarrow$ 大臂移向下一焊点。
    
      
    

### 四、 关键优势总结

- **精度保障：** 大臂谐波近乎零齿隙，末端音圈柔性导轨无摩擦死区，整机定位精度可达 **$\pm 0.03 \text{ mm}$** 以内。
    
      
    
- **安全性：** 烙铁头垂直向为音圈柔顺驱动，即使视觉深度存在微小误差，也不会对 PCB 和引脚产生硬性机械过载。
    
      
    
- **热稳定：** 机械弹簧平衡自重，电机轻载运转，长时连续焊接无几何热漂移。
