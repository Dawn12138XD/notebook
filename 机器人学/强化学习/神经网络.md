
# 神经网络基本构成

深度神经网络的骨架主要由以下 6 大核心模块构成：

## 1. 神经元基本运算单元（Perceptron Node）

* **线性组合（Weighted Sum）：** $z = W^T x + b$，其中 $W$ 为权重（Weight，决定输入特征的重要性），$b$ 为偏置（Bias，调整激活门槛）。
* **矩阵化表示（全连接层 Linear/Dense Layer）：**

$$\mathbf{Z} = \mathbf{X} \mathbf{W} + \mathbf{b}$$
（批处理时 $\mathbf{X} \in \mathbb{R}^{B \times d_{\text{in}}}$，$\mathbf{W} \in \mathbb{R}^{d_{\text{in}} \times d_{\text{out}}}$，$\mathbf{b} \in \mathbb{R}^{1 \times d_{\text{out}}}$）。

## 2. 非线性激活函数（Activation Function）

没有激活函数，多层神经网络等价于单个矩阵相乘（线性变换的复合仍是线性变换），无法拟合非线性问题。

* **ReLU（Rectified Linear Unit）：** 。计算极快，有效缓解正半轴梯度消失，是强化学习和全连接层最常用的默认选择。$$f(x) = \max(0, x)$$
* **Leaky ReLU / ELU：** 解决 ReLU 在 $x < 0$ 时梯度完全归零导致“神经元死亡”的问题。
		Leaky ReLU*  **数学公式：   $f(x) = \max(\alpha x, x) = \begin{cases} x, & \text{if } x \ge 0 \\ \alpha x, & \text{if } x < 0 \end{cases}$            导数：   $f'(x) = \begin{cases} 1, & \text{if } x > 0 \\ \alpha, & \text{if } x < 0 \end{cases}$

	ELU（Exponential Linear Unit）-**数学公式： $f(x) = \begin{cases} x, & \text{if } x \ge 0 \\ \alpha (e^x - 1), & \text{if } x < 0 \end{cases}$ **导数：**$f'(x) = \begin{cases} 1, & \text{if } x \ge 0 \\ f(x) + \alpha = \alpha e^x, & \text{if } x < 0 \end{cases}$

	Sigmoid（Logistic 函数）：* **数学公式：**$\sigma(x) = \frac{1}{1 + e^{-x}}$   **导数：**$\sigma'(x) = \sigma(x)(1 - \sigma(x))$$

## 3. 常见网络层架构（Layer Architectures）

* **全连接层（Linear / MLP）：** 节点间两两全互联，常用于处理低维向量特征（如位姿、关节位置速度等物理状态）。
* **卷积层（Conv2D）：** 利用局部感受野与权重共享提取空间特征，常用于处理视觉观测输入（如 Atari 游戏画面、深度图）。
* **循环层（LSTM / GRU）：** 具备时序记忆能力，常用于部分可观测环境（POMDP）中的连续状态建模。

## 4. 损失函数（Loss Function / Objective）

定义优化方向的标尺。

* **均方误差（MSE Loss）：** 强化学习中拟合 Q 值最标准的回归损失，$L = \frac{1}{B} \sum (y_i - \hat{y}_i)^2$。
* **Huber Loss / Smooth L1 Loss：** 当误差较小时为二次函数，误差较大时退化为一次线性函数，能有效抑制强化学习中异常大回报导致的梯度爆炸。
* **交叉熵损失（Cross-Entropy）：** 监督分类或策略网络（Policy Network）常用的分布对齐损失。

## 5. 优化算法（Optimizers）

决定如何利用反向传播算出的梯度去平稳修改参数 $\theta$。

* **SGD（Stochastic Gradient Descent）：** 最基础的梯度下降，易陷入鞍点或局部震荡。
* **Momentum（动量法）：** 引入一阶动量模拟物理惯性，加速平坦区域收敛并冲过局部极值。
* **Adam（Adaptive Moment Estimation）：** 结合动量与自适应学习率调节，对超参数鲁棒性强，是 DQN、SAC 等现代强化学习算法的通用标准优化器。
### 1. 前向传播（Forward Propagation）：计算预测值

前向传播是数据**从输入端流向输出端**的过程。

- **输入：** 系统的当前状态特征向量 $s$（例如机械臂各关节当前的角度、角速度，或游戏图像像素）。
    
- **计算过程：** 数据穿过多层神经元，每一层依次执行**仿射变换（矩阵乘法 + 偏置）**与**非线性激活**，逐层提取更抽象的特征。
    
- **输出：** 最终输出层给出每个离散动作对应的 Q 值预测向量 $\mathbf{Q}(s; \theta) = [Q(s, a_1), Q(s, a_2), \dots, Q(s, a_m)]$。
    
- **核心目的：** 得出预测结果，为决策提供依据，并与真实/目标值（如 TD Target）对比计算出当前的误差（Loss）。

##### 单个样本的逆向推导（以识别数字“2”为例）

针对某一个具体样本，由于网络还没学好，输出层会给出一组混乱的激活值（如 $0.5, 0.8, 0.2$ 等）：

1. **确立输出层的“期望变化”**：
    
    - 既然目标是数字 2，我们就希望代表“2”的神经元激活值变大，其他神经元的激活值变小。
        
    - **调整幅度与差距成正比**：差距越大的神经元（比如原本应该接近 0 却很大的，或应该接近 1 却很小的），给它的期望变化权重越大。
        
2. **如何满足单个神经元的愿望？（三条路径）** 一个神经元的激活值取决于前一层的加权和加偏置：$a = \sigma(\sum w \cdot a_{\text{prev}} + b)$。要提升这个激活值，有三种方法：
    
    - **增大偏置（Bias）**。
        
    - **增大权重（Weight）**：
        
        - **关键原则**：只给“前一层本来就很亮（激活值大）”的连接增加权重，收益才最大；如果前一层神经元本来就是暗的（激活值接近 0），调大连接权重对总和几乎没贡献。
            
        - 这类似于神经科学中的赫布理论（_Hebbian Theory_）——“一起放电的神经元会紧密连接（Neurons that fire together, wire together）”。
            
    - **改变前一层的激活值（Activation）**：
        
        - 如果与“2”相连的权重是正的，就希望前一层的输入神经元变亮；如果是负的，就希望变暗。
            
        - 期望变化的幅度，同样与**对应权重的大小成正比**。
            
3. **汇总需求，逆向层层递归（算法的核心跃迁）**：
    
    - 最后一层的每一个神经元（0 到 9）都会对倒数第二层的各个神经元提出自己的“愿望清单”。
        
    - 把所有输出神经元对倒数第二层某个神经元的期望**按权重比例叠加起来**，就得到了倒数第二层各个神经元应该如何变化的“综合需求表”。
        
    - 拿到这份表后，**递归重复上述过程**：继续推导如何调整倒数第二层的权重和偏置，以及倒数第三层的期望变化……一路向后推进，直到输入层。

##### 从单个样本到全量更新（SGD 随机梯度下降）

- **理论上的梯度**：每个样本都会提出一套自己理想的权重调整方案。严格的梯度下降必须遍历成千上万个训练样本，求出所有样本期望调整的**平均值**，才能迈出精确的一步。但这极度耗时。
    
- **实际的妥协（SGD）**：将数据随机打乱，分成若干小批次（Mini-batch，例如每批 100 张图）。
    
- **形象比喻**：用一个小批次估算出来的方向去更新参数，轨迹不再是精准优雅的匀速下坡，而更像一个“步伐较快、东倒西歪但大方向在向下的醉汉”。虽然步子不够稳，但计算极快，最终依然能够收敛到局部最优解。

	- SGD（Stochastic Gradient Descent，随机梯度下降）

		**作用：机器学习最基础的优化器，用来最小化损失、更新模型参数**

		**核心思想

		普通 GD（梯度下降）：**每一步用全部数据算梯度**，开销大。 SGD：**每次随机抽 1 个样本（实际多用 mini-batch 一小批）算梯度，当成全局梯度的估计**，更新参数University
    
    $$\theta \leftarrow \theta - \alpha \nabla_\theta L(\theta)$$
    
- **核心目的：** 明确“输出的偏差具体是哪一层、哪一个神经元的权重导致的”，从而定向修正参数，让下一次前向传播时的预测更准确。

#### 6. 训练关键超参数（Hyperparameters）

* **学习率（Learning Rate, $\alpha$）：** 控制单步更新跨度。过大易导致数值爆炸或发散，过小会导致收敛极慢。
* **批大小（Batch Size, $B$）：** 决定每次反向传播使用多少条样本的平均梯度。
* **权重初始化（Weight Initialization）：** 如 He/Kaiming 初始化、Xavier 初始化，确保前向传播和反向传播初期信号方差稳定，防止网络刚开始训练就梯度归零或爆炸。

- **损失函数：

$$L(\theta) = \mathbb{E}\left[ \left( r + \gamma \max_{a'} Q(s', a'; \theta) - Q(s, a; \theta) \right)^2 \right]$$

    
- **计算过程：** 基于微积分的**链式法则（Chain Rule）**，由输出层向后逐层求偏导数，计算出损失对网络中每一个权重矩阵 $W$ 和偏置 $b$ 的梯度：
    
    $$\nabla_\theta L(\theta) = \frac{\partial L}{\partial \theta}$$
    
- **输出：** 各层可学习参数的梯度方向与大小。
    
- **参数更新（梯度下降）：** 得到梯度后，优化器（如 Adam、SGD）沿着梯度的反方向推进一步，更新网络参数：
    
    $$\theta \leftarrow \theta - \alpha \nabla_\theta L(\theta)$$
    
- **核心目的：** 明确“输出的偏差具体是哪一层、哪一个神经元的权重导致的”，从而定向修正参数，让下一次前向传播时的预测更准确。
