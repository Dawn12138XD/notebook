# off-policy

### 一、On-policy 与 Off-policy 的核心区别

在强化学习中，存在两个策略角色：

1. **行为策略（Behavior Policy $\beta$）：** 负责在环境中执行动作、探索并收集样本 $(s, a, r, s')$。
    
2. **目标策略（Target Policy $\pi$）：** 算法正在计算价值、梯度并试图优化的策略。
    

| **对比维度**                      | **On-policy（同策略）**                                                                                                           | **Off-policy（异策）**                                                                                                                                |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **策略关系**                      | **$\beta = \pi$**（两者必须是同一个策略）                                                                                                | **$\beta \neq \pi$**（两者可以完全不同）                                                                                                                    |
| **更新逻辑**                      | “我亲自用当前的这套动作逻辑去试，根据我犯的错或拿到的奖赏，立刻更新我自己的逻辑。”                                                                                   | “别人去试、过去的我试、或者我按一套探索机制去试，但我用它来更新另一套更优的目标策略。”                                                                                                      |
| **典型 Bellman 更新公式**           | **SARSA：**<br><br>  <br><br>$Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma Q(s', a') - Q(s, a)]$，其中 $a'$ 是按当前策略实际选出的下一个动作。 | **Q-Learning：**<br><br>  <br><br>$Q(s, a) \leftarrow Q(s, a) + \alpha [r + \gamma \max_{a'} Q(s', a') - Q(s, a)]$，更新时强行假设下一步取最大值（贪婪策略），而不论实际走了什么。 |
| **能否使用经验回放池（Replay Buffer）？** | **不能。** 历史数据是“旧策略”生成的，不能用来直接更新“当前新策略”。数据用一次就必须丢弃。                                                                            | **能。** 只要是合法环境状态转移，历史数据、其他智能体的数据都可以存入池子打乱复用。                                                                                                      |
| **样本利用效率**                    | 低（Sample Inefficient），极度消耗算力或交互次数。                                                                                           | 高（Sample Efficient），一条经验可以多次重采样训练。                                                                                                                |
| **训练稳定性**                     | 通常较稳定，方差较低。                                                                                                                  | 搭配神经网络函数近似时容易面临“致命三要素”（非线性近似、自举、异策更新），导致训练震荡或发散。                                                                                                  |
| **经典算法**                      | SARSA、A3C、TRPO、PPO。                                                                                                          | Q-Learning、DQN、DDPG、TD3、SAC。                                                                                                                      |

**Online / Offline：** 能不能“连上环境动手”的事——**你是有个能随时点进去试错的模拟器（Online），还是手里只有一份写死的操作日志（Offline）？**

# Q-learning
## 公式：贝尔曼最优方程，最优 $Q$ 函数

$$Q^*(s,a) = \sum_{s'} P(s' \mid s,a) \left[ R(s,a,s') + \gamma \max_{a'} Q^*(s',a') \right]$$

### 分项释义
- $\gamma$：折扣因子
    
      
    - 满足 $0 \le \gamma \le 1$，用于调节未来奖励的权重。折扣因子越小，智能体越重视即时奖励；折扣因子越大，智能体越重视长期回报。
        
          
        
- $\max_{a'} Q^*(s',a')$：下一个状态的最大未来价值
    
      
    - 表示到达下一个状态 $s'$ 后，在所有可能动作 $a'$ 中选择 $Q$ 值最大的动作所对应的最优价值。
	这里的a‘和
          
- ==🔴$P(s' \mid s,a)$：状态转移概率==
    
      
    - 表示当前处于状态 $s$ 时，执行动作 $a$ 后转移到下一个状态 $s'$ 的概率。
        
    - 通过P * R的求和，得出最优未来策略的期望

    -  输入a，不一定导致S2，也可能有其他S’故可以进行期望计算
        
- ==🔴$R(s,a,s')$：即时奖励==
    
      
    - 表示从状态 $s$ 执行动作 $a$，转移到状态 $s'$ 时立即获得的奖励。
        


        

### 公式理解

		- 结果生成一个S x A大小的矩阵，可得所有状态S选择所有A的期望

![[Attachments/Pasted image 20261024140317.png|1056]]

该公式表示：当前状态下执行某个动作的最优价值，等于所有可能的下一状态对应的即时奖励与折扣后的最优未来价值之和，再按照状态转移概率求期望。 

  

其中：

  

- $R(s,a,s')$ 表示当前动作带来的即时奖励。
    
      
    
- $\gamma \max_{a'} Q^*(s',a')$ 表示下一状态的最优未来价值经过折扣后的价值。
    
      
    
- $\sum_{s'} P(s' \mid s,a)$ 表示对所有可能的下一状态进行概率加权求和。

## 由于解析方程依赖转移核 \(P(s'|s,a)\) 和奖励 R；真实环境里我们经常拿不到 P，没法直接求解方程组。

## Q-learning==🟠(使用实际观测值替代P和R)==

Q-Learning 是一种经典的强化学习算法，其核心目标是让智能体（Agent）在未知环境中通过试错学习，学会在每个状态下做出最优决策，即学习一个动作价值函数 $Q(s, a)$。

  

## 一、 初始化阶段

在开始训练之前，需要准备好核心的数据结构与超参数：

  

1. **Q-Table（Q表）**：
    
      
    - **结构**：行表示所有可能的状态 $s$，列表示所有可能的动作 $a$，表格中的每个元素对应一个 $Q(s, a)$ 值。
        
        ![[Attachments/Pasted image 20261024141804.png|430]]  
        
    - **初始化**：通常将 Q 表中所有值初始化为 **0**。这表示在训练开始前，智能体对任何动作的好坏一无所知。
        
          
        
2. **超参数设置**：
    
      
    - **学习率（Learning Rate, $\alpha$）**：控制学习的步长。
        
          
        
    - **折扣因子（Discount Factor, $\gamma$）**：决定未来奖励对当前决策的影响程度。
        
          
        
    - **探索率（$\epsilon$, Epsilon）**：用在动作选择模块，决定智能体进行随机探索的概率。
        
          
        
    - **训练回合数（Episodes）**：指定智能体在环境中训练的总回合数，避免无限期训练。
        
          
        

## 二、 核心思想：用“样本”替代“期望”

在传统的动态规划中，更新价值需要计算所有可能状态转移的数学期望：
$$Q^*(s, a) = \sum_{s'} P(s'\vert{}s, a) \left[ R(s, a, s') + \gamma \max_{a'} Q^*(s', a') \right]$$

而在 Q-Learning 中，智能体从状态 $s$ 执行动作 $a$ 得到具体的即时奖励 $r$ 和新状态 $s'$，这个组合 $(s, a, r, s')$ 就是对环境真实动态的一次“采样”。$$\text{TD Target} = r + \gamma \max_{a'} Q(s', a')$$
算法利用这个样本算出的 **TD 目标** 来更新 Q 值：

  

- **$r$**：是对 $R(s, a, s')$ 的一次采样。
    
      
    
- **$\max_{a'} Q(s', a')$**：是对 $\max_{a'} Q^*(s', a')$ 的当前估计。
    
      
    

## 三、 算法流程：训练循环

整个训练过程由多个回合（Episode）组成，每个回合包含以下三个核心步骤：

  

### 1. 选择动作：$\epsilon\text{-greedy}$（ $\epsilon$-贪婪策略）

为了平衡“探索”（探索未知好坏的动作）与“利用”（利用已知的最优动作），通常采用 $\epsilon\text{-greedy}$ 策略：

  

- 生成一个 $0 \sim 1$ 之间的随机数：
    
      
    - 若 **$\text{随机数} < \epsilon$**：随机选择当前状态 $s$ 下的一个动作 $a$（**探索**）。
        
          
        
    - 若 **$\text{随机数} \ge \epsilon$**：在 Q 表中查找状态 $s$ 对应的行，选择使 $Q(s, a)$ 最大的动作 $a$（**利用**）。
        
          
        

> **$\epsilon$ 动态调整（Epsilon Decay）**： 在训练初期，智能体对环境一无所知，Q 表价值参考价值低，因此 $\epsilon$ 设得较高（如 $1.0$）以进行充分的随机探索。随着训练进行，Q 表趋于可靠，$\epsilon$ 逐渐衰减（如降至 $0.01$），让智能体越来越倾向于利用已学知识。
> 
>   

### 2. 执行动作并观察结果

智能体在环境中执行动作 $a$ 后，环境会返回以下关键信息：

  

- **新状态 ($s'$)**：执行动作后的新状态。
    
      
    
- **奖励 ($r$)**：执行该动作后立即获得的即时奖励。
    
      
    
- **完成标志 (Done)**：布尔值，表示当前回合是否结束。
    
      
    
- **其他调试信息 (Info)**：可忽略。
    
      
    

### 3. 更新 Q-Table（增量式学习）

这是 Q-Learning 最核心的步骤，包含三个计算环节：

  

- **第一步：计算 TD 目标（Temporal-Difference Target）**
    
    正是这个理论真实值Q（s,a）（动作价值函数）在单次采样下的**无偏/近似代理估计值**：
    
    $$\text{TD Target} = r + \gamma \max_{a'} Q(s', a')$$
    
    (注：若 $s'$ 是终止状态，则未来没有奖励，后面一项为零。)
    
      
    
- **第二步：计算 TD 误差（TD Error）**
    
      
    
    $$\text{TD Error} = \text{TD Target} - Q(s, a)$$
    
- **第三步：更新旧的 $Q(s, a)$ 值**
    
      
    
    $$Q(s, a) \leftarrow Q(s, a) + \alpha \times \text{TD Error}$$
    
    将其展开为增量式更新的经典形式：
    
      
    
    $$Q(s, a) \leftarrow (1 - \alpha)Q(s, a) + \alpha \left( r + \gamma \max_{a'} Q(s', a') \right)$$
    
    其中包含两部分：
    
      
    - **旧知识 $(1 - \alpha)Q(s, a)$**：保留一部分之前的估计。
        
          
        
    - **新知识 $\alpha \left( r + \gamma \max_{a'} Q(s', a') \right)$**：融入本次采样带来的最新经验。
        
        - ==🟠相当于只更新了一个真实的r==
        

## 四、 为什么 Q-Learning 可行？

1. **基于采样**：每次更新只基于单次采样，无需知道环境的全局概率分布。
    
      
    
2. **渐进收敛**：根据大数定律，如果智能体与环境交互无限多次，采样结果的平均值会收敛到理论上的期望值。通过反复迭代更新， $Q(s, a)$ 会逐渐逼近最优动作价值函数 $Q^*(s, a)$。
    
      
    

训练结束后，Q 表中存储的就是近似最优的动作价值函数。此时无需再进行探索或采样，只需在任意状态 $s$ 下查询 Q 表，直接选择使 $Q(s, a)$ 最大的动作 $a$，即可执行最优策略。

## Fixed-Q-targets 策略


### 目标值（Target）
在传统的监督学习中，样本标签 $y$ 是固定的常数（例如图像分类中的真实标签）。

而在标准 Q-Learning 中，目标值（Target）是由当前参数计算出来的：

$$y = r + \gamma \max_{a'} Q(s', a'; \theta)$$



### 损失函数：
[[神经网络#4. 损失函数（Loss Function / Objective）]]


$$L(\theta) = \mathbb{E}\left[ \left( \underbrace{r + \gamma \max_{a'} Q(s', a'; \theta)}_{\text{Target（目标值）}} - \underbrace{Q(s, a; \theta)}_{\text{Prediction（预测值）}} \right)^2 \right]$$

#### 参数解释
##### 真实的即时奖励 $r$
 - 当智能体执行完动作 $a$ 后，环境发生转移，掉入了新的状态 $s'$，并吐出一个真实的即时奖励 $r$。
 - 
##### 当前估计值$Q(s, a)$ 

- **它对应的主体**：你在状态 $s$ 选择了动作 $a$。
    
- **它代表的含义**：在没有迈出这一步之前，网络对 $(s, a)$ 这个决定的长期价值有一个**先验预估**（Prior Estimate）。
    
- **它的角色**：它是待修正的**被更新方（旧估计）**。我们之所以算 Loss、算梯度，目标就是把 $Q(s, a)$ 的数值拉向一个更准确的值。因此在误差公式中，它是作为基准项被减去的那个“旧预测”。

##### 下步最优值$Q(s', a')$ 

$Q(s', a')$ 是**下一步状态的估计**，它参与组成了**更新的目标（Target）**。

- 智能体站在新状态 $s'$ 往未来看：未来的价值是多少？我们不知道真实值，所以只能再次用网络去估计**下一步的最佳回报**  $\max_{a'} Q(s', a')$。
    
- 虽然 $Q(s', a')$ 也是网络“估”出来的，但**它加了一层已经成真的客观现实 $r$**。
    
- 组合起来的 $r + \gamma \max_{a'} Q(s', a')$ 被称为 **TD Target（时序差分目标）**，它代表“站在此时此刻，基于已经拿到手的一步真实奖励，为过去那个决策 $(s, a)$ 重新计算出的更好参考值”。
##### 均方误差（MSE, Mean Squared Error）
**1，“先算误差，再取平方，最后求平均”
	
- 误差（Error ： $y - \hat{y}$）
	 - $\left( r + \gamma \max_{a'} Q(s', a'; \theta) - Q(s, a; \theta) \right)$
- 方（Squared ： $(y - \hat{y})^2$）
	- $\left( \dots \right)^2$
- 均（Mean ：对所有样本求平均）
	- $\mathbb{E}\left[ \dots \right]$

**2，均方误差（MSE）的核心作用**

- **提供连续可微的凸优化曲面**：
    - 平方项消除了==🔴方向正负号抵消的问题==，并且在实数域内处处光滑可导（避免了绝对值在 0 点不可导的折角）。
    - 对于单层线性模型，MSE 损失曲面是严格的凸函数（凹碗状），全局最优解唯一存在；对于多层非线性网络，它也能提供平滑连续的局部下降坡度。
- **自适应误差惩罚（误差敏感性）**
    - 当误差较小（如 ∣e∣<1\vert{}e\vert{} < 1∣e∣<1）时，平方操作会衰减其权重，避免对微小扰动过度敏感；
    - 当误差较大（如 ∣e∣≫1\vert{}e\vert{} \gg 1∣e∣≫1）时，==🔴平方操作会呈二次方放大该误差==，强迫梯度优先更新偏差严重的反例。
- **统计学意义上的最优逼近**
    - 在高斯噪声假设下，最小化均方误差等价于**最大似然估计（Maximum Likelihood Estimation, MLE）**，它引导模型逼近目标值的条件期望。


    

### 策略解释：解耦预测与目标:


    
- **很久以前的参数 $\theta^-$（Target Network / 目标网络）：** 负责生成目标值 $y$，参数冻结，为梯度更新提供一个相对静止的参考基准。$$y = r + \gamma \max_{a'} Q(s', a'; \theta^-)$$

	- 在强化学习代码中，$y$ 是通过神经网络算出来的，

		- 只要有真实奖励 $r$ 注入，计算出来的目标值 $y$ 就会比当前状态的估计值**更贴近真实世界一步**。
		- 即使 $\max Q(s', a'; \theta^-)$ 带有偏差，乘以折扣因子 $\gamma$（通常是 0.99）后，这个偏差的影响力也会被逐步衰减压制
	- **自举法（Bootstrapping）修正收敛
		- 动态规划的收缩映射（Contraction Mapping）：
			在贝尔曼最优算子（Bellman Operator）的数学证明中，更新公式具备压缩映射性质。只要真实奖励 $r$ 持续输入，即便每次使用的参考基准 $\theta^-$ 是粗糙甚至不准的，经过反复的“前进一步 $\rightarrow$ 定期同步”循环，Q 值与真实最优价值函数之间的误差上限会以 $\gamma$ 的速度指数级衰减。

- **最新参数 $\theta$（Evaluation Network / 估计网络）：** 负责预测当前的 $Q(s, a; \theta)$，步步更新，快速适应。
$$Q_{\text{eval}} = Q(s, a; \theta)$$
- **反向传播与梯度更新阶段：只动 $\theta$
	利用均方误差计算单步损失函数
$$L(\theta) = \mathbb{E} \left[ \left( y - Q(s, a; \theta) \right)^2 \right]$$
- **求导更新**：$$\nabla_\theta L(\theta) = -2 \mathbb{E} \left[ \left( y - Q(s, a; \theta) \right) \nabla_\theta Q(s, a; \theta) \right]$$
    **更新当前估计网络的参数 $\theta$**：$$\theta \leftarrow \theta - \eta \nabla_\theta L(\theta)$$
    **更新固定参数$\theta^-$ 
	    **硬更新（Hard Update，原生 DQN 方案）**： 平时完全冻结 $\theta^-$。每经过固定的步数 $C$（例如每 1000 步或 2000 步），直接把 $\theta$ 的权重整包拷贝覆盖给 $\theta^-$：$$\theta^- \leftarrow \theta$$
		**软更新（Soft Update，DDPG / SAC 常用方案）**： 每个训练 step 都让 $\theta^-$ 缓慢向 $\theta$ 移动一小步，通过平滑衰减因子 $\tau \ll 1$（例如 $\tau = 0.005$）：$$\theta^- \leftarrow \tau \theta + (1 - \tau) \theta^-$$
    
    
如果两边都使用同一套**最新参数 $\theta$**，就会导致“移动靶问题”（Moving Target Problem）：

- 每次更新参数 $\theta$ 试图让 $Q(s, a; \theta)$ 靠近目标 $y$；
    
- 但更新 $\theta$ 的同时，下一步的目标值 $y$ 也跟着改变；
    
- 这相当于射击时“靶子跟着枪口一起晃动”，极易引发自激振荡，使神经网络预测发散。
# off-policy

### 一、On-policy 与 Off-policy 的核心区别

在强化学习中，存在两个策略角色：

1. **行为策略（Behavior Policy $\beta$）：** 负责在环境中执行动作、探索并收集样本 $(s, a, r, s')$。
    
2. **目标策略（Target Policy $\pi$）：** 算法正在计算价值、梯度并试图优化的策略。
    

| **对比维度**                      | **On-policy（同策略）**                                                                                                           | **Off-policy（异策）**                                                                                                                                |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **策略关系**                      | **$\beta = \pi$**（两者必须是同一个策略）                                                                                                | **$\beta \neq \pi$**（两者可以完全不同）                                                                                                                    |

# Q-learning
## 公式：贝尔曼最优方程，最优 $Q$ 函数

$$Q^*(s,a) = \sum_{s'} P(s' \mid s,a) \left[ R(s,a,s') + \gamma \max_{a'} Q^*(s',a') \right]$$

### 分项释义
- $\gamma$：折扣因子
    
      
    - 满足 $0 \le \gamma \le 1$，用于调节未来奖励的权重。折扣因子越小，智能体越重视即时奖励；折扣因子越大，智能体越重视长期回报。
        
          
        
- $\max_{a'} Q^*(s',a')$：下一个状态的最大未来价值
    
      
    - 表示到达下一个状态 $s'$ 后，在所有可能动作 $a'$ 中选择 $Q$ 值最大的动作所对应的最优价值。
	这里的a‘和
          
- ==🔴$P(s' \mid s,a)$：状态转移概率==
    
      
    - 表示当前处于状态 $s$ 时，执行动作 $a$ 后转移到下一个状态 $s'$ 的概率。
        
    - 通过P * R的求和，得出最优未来策略的期望

    -  输入a，不一定导致S2，也可能有其他S’故可以进行期望计算
        
- ==🔴$R(s,a,s')$：即时奖励==
    
      
    - 表示从状态 $s$ 执行动作 $a$，转移到状态 $s'$ 时立即获得的奖励。
        


        

### 公式理解

		- 结果生成一个S x A大小的矩阵，可得所有状态S选择所有A的期望

![[Attachments/Pasted image 20261024140317.png|606]]

该公式表示：当前状态下执行某个动作的最优价值，等于所有可能的下一状态对应的即时奖励与折扣后的最优未来价值之和，再按照状态转移概率求期望。 

  

其中：

  

- $R(s,a,s')$ 表示当前动作带来的即时奖励。
    
      
    
- $\gamma \max_{a'} Q^*(s',a')$ 表示下一状态的最优未来价值经过折扣后的价值。
    
      
    
- $\sum_{s'} P(s' \mid s,a)$ 表示对所有可能的下一状态进行概率加权求和。

## 由于解析方程依赖转移核 \(P(s'|s,a)\) 和奖励 R；真实环境里我们经常拿不到 P，没法直接求解方程组。

## Q-learning==🟠(使用实际观测值替代P和R)==

Q-Learning 是一种经典的强化学习算法，其核心目标是让智能体（Agent）在未知环境中通过试错学习，学会在每个状态下做出最优决策，即学习一个动作价值函数 $Q(s, a)$。

  

## 一、 初始化阶段

在开始训练之前，需要准备好核心的数据结构与超参数：

  

1. **Q-Table（Q表）**：
    
      
    - **结构**：行表示所有可能的状态 $s$，列表示所有可能的动作 $a$，表格中的每个元素对应一个 $Q(s, a)$ 值。
        
        ![[Attachments/Pasted image 20261024141804.png|430]]  
        
    - **初始化**：通常将 Q 表中所有值初始化为 **0**。这表示在训练开始前，智能体对任何动作的好坏一无所知。
        
          
        
2. **超参数设置**：
    
      
    - **学习率（Learning Rate, $\alpha$）**：控制学习的步长。
        
          
        
    - **折扣因子（Discount Factor, $\gamma$）**：决定未来奖励对当前决策的影响程度。
        
          
        
    - **探索率（$\epsilon$, Epsilon）**：用在动作选择模块，决定智能体进行随机探索的概率。
        
          
        
    - **训练回合数（Episodes）**：指定智能体在环境中训练的总回合数，避免无限期训练。
        
          
        

## 二、 核心思想：用“样本”替代“期望”

在传统的动态规划中，更新价值需要计算所有可能状态转移的数学期望：
$$Q^*(s, a) = \sum_{s'} P(s'\vert{}s, a) \left[ R(s, a, s') + \gamma \max_{a'} Q^*(s', a') \right]$$

而在 Q-Learning 中，智能体从状态 $s$ 执行动作 $a$ 得到具体的即时奖励 $r$ 和新状态 $s'$，这个组合 $(s, a, r, s')$ 就是对环境真实动态的一次“采样”。$$\text{TD Target} = r + \gamma \max_{a'} Q(s', a')$$
算法利用这个样本算出的 **TD 目标** 来更新 Q 值：

  

- **$r$**：是对 $R(s, a, s')$ 的一次采样。
    
      
    
- **$\max_{a'} Q(s', a')$**：是对 $\max_{a'} Q^*(s', a')$ 的当前估计。
    
      
    

## 三、 算法流程：训练循环

整个训练过程由多个回合（Episode）组成，每个回合包含以下三个核心步骤：

  

### 1. 选择动作：$\epsilon\text{-greedy}$（ $\epsilon$-贪婪策略）

为了平衡“探索”（探索未知好坏的动作）与“利用”（利用已知的最优动作），通常采用 $\epsilon\text{-greedy}$ 策略：

  

- 生成一个 $0 \sim 1$ 之间的随机数：
    
      
    - 若 **$\text{随机数} < \epsilon$**：随机选择当前状态 $s$ 下的一个动作 $a$（**探索**）。
        
          
        
    - 若 **$\text{随机数} \ge \epsilon$**：在 Q 表中查找状态 $s$ 对应的行，选择使 $Q(s, a)$ 最大的动作 $a$（**利用**）。
        
          
        

> **$\epsilon$ 动态调整（Epsilon Decay）**： 在训练初期，智能体对环境一无所知，Q 表价值参考价值低，因此 $\epsilon$ 设得较高（如 $1.0$）以进行充分的随机探索。随着训练进行，Q 表趋于可靠，$\epsilon$ 逐渐衰减（如降至 $0.01$），让智能体越来越倾向于利用已学知识。
> 
>   

### 2. 执行动作并观察结果

智能体在环境中执行动作 $a$ 后，环境会返回以下关键信息：

  

- **新状态 ($s'$)**：执行动作后的新状态。
    
      
    
- **奖励 ($r$)**：执行该动作后立即获得的即时奖励。
    
      
    
- **完成标志 (Done)**：布尔值，表示当前回合是否结束。
    
      
    
- **其他调试信息 (Info)**：可忽略。
    
      
    

### 3. 更新 Q-Table（增量式学习）

这是 Q-Learning 最核心的步骤，包含三个计算环节：

  

- **第一步：计算 TD 目标（Temporal-Difference Target）**
    
    正是这个理论真实值Q（s,a）（动作价值函数）在单次采样下的**无偏/近似代理估计值**：
    
    $$\text{TD Target} = r + \gamma \max_{a'} Q(s', a')$$
    
    (注：若 $s'$ 是终止状态，则未来没有奖励，后面一项为零。)
    
      
    
- **第二步：计算 TD 误差（TD Error）**
    
      
    
    $$\text{TD Error} = \text{TD Target} - Q(s, a)$$
    
- **第三步：更新旧的 $Q(s, a)$ 值**
    
      
    
    $$Q(s, a) \leftarrow Q(s, a) + \alpha \times \text{TD Error}$$
    
    将其展开为增量式更新的经典形式：
    
      
    
    $$Q(s, a) \leftarrow (1 - \alpha)Q(s, a) + \alpha \left( r + \gamma \max_{a'} Q(s', a') \right)$$
    
    其中包含两部分：
    
      
    - **旧知识 $(1 - \alpha)Q(s, a)$**：保留一部分之前的估计。
        
          
        
    - **新知识 $\alpha \left( r + \gamma \max_{a'} Q(s', a') \right)$**：融入本次采样带来的最新经验。
        
          
        

## 四、 为什么 Q-Learning 可行？

1. **基于采样**：每次更新只基于单次采样，无需知道环境的全局概率分布。
    
      
    
2. **渐进收敛**：根据大数定律，如果智能体与环境交互无限多次，采样结果的平均值会收敛到理论上的期望值。通过反复迭代更新， $Q(s, a)$ 会逐渐逼近最优动作价值函数 $Q^*(s, a)$。
    
      
    

训练结束后，Q 表中存储的就是近似最优的动作价值函数。此时无需再进行探索或采样，只需在任意状态 $s$ 下查询 Q 表，直接选择使 $Q(s, a)$ 最大的动作 $a$，即可执行最优策略。

### Fixed-Q-targets 策略


#### 目标值（Target）
在传统的监督学习中，样本标签 $y$ 是固定的常数（例如图像分类中的真实标签）。

而在标准 Q-Learning 中，目标值（Target）是由当前参数计算出来的：

$$y = r + \gamma \max_{a'} Q(s', a'; \theta)$$
#### 损失函数：

$$L(\theta) = \mathbb{E}\left[ \left( r + \gamma \max_{a'} Q(s', a'; \theta) - Q(s, a; \theta) \right)^2 \right]$$

如果两边都使用同一套**最新参数 $\theta$**，就会导致“移动靶问题”（Moving Target Problem）：

- 每次更新参数 $\theta$ 试图让 $Q(s, a; \theta)$ 靠近目标 $y$；
    
- 但更新 $\theta$ 的同时，下一步的目标值 $y$ 也跟着改变；
    
- 这相当于射击时“靶子跟着枪口一起晃动”，极易引发自激振荡，使神经网络预测发散。
    

**解决方案：解耦预测与目标。**

- **最新参数 $\theta$（Evaluation Network / 估计网络）：** 负责预测当前的 $Q(s, a; \theta)$，步步更新，快速适应。
    
- **很久以前的参数 $\theta^-$（Target Network / 目标网络）：** 负责生成目标值 $y$，参数冻结，为梯度更新提供一个相对静止的参考基准。
